# Year 1 PCB design, build and test (Engineering Skills 1, 2024)

OrCAD Capture and Allegro PCB Editor.

* `electronic-dice/`: designed, laid out, built and tested an electronic dice on a double-sided PCB (74HC132, 74HC175, 7 LEDs). Deliverables: schematic, layouts, photomasks, assembly drawing and BOM.
* `advanced-orcad-board/`: a 22-part logic board (74HC14, 74HC164, 74HC86, LM2931 regulator). After testing the first board I re-routed IC connections to the bottom layer.
* `op-amp-board/`: an MCP6291 op-amp circuit, schematic and layout.
