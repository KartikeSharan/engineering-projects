# Real-Time Computer Systems 3 labs (Arm Cortex-M4)

STM32F4 Discovery (STM32F407VG) in Keil MDK-ARM (µVision).

* `lab1-assembly/`: Thumb assembly string routines called from C. I stepped through them in the debugger, tracking SP, LR and PC across each call and return. The routines were provided.
* `lab2-c-and-assembly/` and `lab3-interrupts-timers/`: lab code for compiler output and linker maps (Lab 2), and GPIO and timer interrupts (Lab 3).

Most of this code was supplied by the course (Arm University Program) and ST (`stm32f4xx_it.*`); it is kept here as the record of what I worked with.
