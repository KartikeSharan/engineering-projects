# Quine–McCluskey Boolean Minimiser (Python)

Full implementation of the Quine–McCluskey algorithm with **don't-care
support**: truth-table input, prime-implicant generation by iterative
combining, essential prime-implicant selection, and a greedy cover for the
remaining minterms, producing a minimal sum-of-products expression. Truth
tables displayed with pandas.

Written as the final assignment for ENG2083 *Introductory Programming 2*
(University of Glasgow).
