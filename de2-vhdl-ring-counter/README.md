# Ring counter on a MAX 10 FPGA (Digital Electronics 2, 2025)

DE10-Lite board in Quartus. I converted a provided 8-bit shift register into a ring counter by feeding its last output back to its input, checked it in a waveform simulation, then clocked it on the board from a push-button and from an external signal generator. The report and lab images are here; the Quartus project files weren't kept.
