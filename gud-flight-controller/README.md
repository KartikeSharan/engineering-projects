# Society flight controller schematic (Glasgow University Drones)

An earlier society project: a flight controller modelled on the Pixhawk 6 connector standard, drawn in KiCad while I was a team member. It was never fabricated (funding). The main copy lives in the society's `GUDrones/flight-controller` repository.

`kicad/` holds the schematic and the component libraries (ICM-20602, ICM-20689 and BMI055 IMUs, PS1240 buzzer, 8 MHz crystal, connectors).
