# Semiconductor device simulation: silicon p-n junction (Electronic Devices 3, 2026)

Synopsys Sentaurus TCAD (Structure Editor and Sentaurus Device). A symmetric silicon p-n junction (10^17 cm^-3 each side, 0.5 µm each side), swept from -1 V to +0.6 V, with and without SRH recombination. `pn_junction_lab/` holds the command files and the I-V results (`*_des.plt`). The command files started from course templates; I set the parameters.
