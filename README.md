# Engineering Projects — Kartike Sharan

Selected hardware and software projects from my BEng in Electrical & Electronic
Engineering at the University of Glasgow (including an exchange semester at
Glasgow College, UESTC, Chengdu).

| Project | Summary |
|---|---|
| [`risc16-cpu`](risc16-cpu/) | 16-bit load-store RISC CPU in Verilog — datapath, multi-cycle FSM control unit, module-level and full-system testbenches, verified in Vivado simulation. Includes the formal design report. |
| [`quine-mccluskey`](quine-mccluskey/) | Boolean-function minimiser in Python implementing the full Quine–McCluskey algorithm with don't-care support. |

More to follow: VHDL designs tested on a MAX 10 (DE10-Lite) FPGA, and STM32
embedded C projects.
