# Engineering Projects: Kartike Sharan

Hardware and software projects from my BEng in Electronics & Electrical Engineering at the University of Glasgow (including an exchange semester at UESTC, Chengdu), my drone society and a drone start-up. Each folder has its own README saying what I did.

## PCB design

| Project | Summary |
|---|---|
| [`atreides-flight-controller`](atreides-flight-controller/) | 6-layer drone flight controller for a start-up; I owned the PCB layout (KiCad) |
| [`gud-drone-devkit`](gud-drone-devkit/) | Solder-free educational drone kit for schools outreach; my electronics design (ESP32-C3, KiCad) |
| [`gud-flight-controller`](gud-flight-controller/) | Society flight controller schematic modelled on the Pixhawk 6 standard (KiCad) |
| [`year1-pcb-design`](year1-pcb-design/) | Electronic dice and logic boards, designed, built and tested (OrCAD, Allegro) |
| [`dp2-orcad-allegro-lab1`](dp2-orcad-allegro-lab1/) | Op-amp board schematic and layout (OrCAD, Allegro) |
